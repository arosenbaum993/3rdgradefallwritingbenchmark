# Grade 3 Fall Writing Benchmark

`index.html` is the on-screen prompt for the Grade 3 ELA writing benchmark. Students read the two sources and the writing task on the computer and write their response on paper. Nothing is typed or submitted through the page.

## Give students the link

1. On GitHub, open **Settings**, then **Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Pick the branch (`main` after this work is merged), folder **/ (root)**, and choose **Save**.
4. Wait about a minute, then open `https://arosenbaum993.github.io/3rdgradefallwritingbenchmark/`.
5. Post that link in Google Classroom or on the class site. The file is named `index.html` so the link works without a file name on the end.

The page has no outside dependencies, so it also works if it is downloaded and opened from a Chromebook's Files app.

## What a student sees

1. A start screen with one **Start** button. If scripts are blocked, the start screen is skipped and the sources and task show right away.
2. Sources on the left and the writing task on the right. Each side scrolls on its own. On a narrow screen the task stacks below the sources with a **Jump to Writing Task** button.
3. Toolbar: Previous and Next move through the sources. Highlight, Notepad, Text Size, Line Reader, Checklist, Full Screen, and Print Paper. Full Screen is hidden when the browser or embedding page does not allow it.
